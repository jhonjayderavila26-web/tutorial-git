# Tutorial Pro Git - Guía de Actividades U2

Este repositorio contiene el tutorial elaborado a partir del libro oficial **Pro Git** (segunda edición), como parte de la Actividad 2 del curso de Ciencia de Datos.

## Estructura del Repositorio

El repositorio contiene la documentación condensada de los siguientes capítulos en formato PDF:

- **Capítulo 1:** Introducción al control de versiones, fundamentos e historia de Git.
- **Capítulo 2:** Fundamentos de Git, manejo de repositorios, ciclo de vida de los archivos y comandos básicos.
- **Capítulo 3:** Ramas en Git (Git Branching), creación, cambio entre ramas, fusión (merge) y resolución de conflictos.

## Comandos de Git Utilizados en el Proceso

1. **Configuración inicial:**
   `git config --global user.name "Tu Nombre"`
   `git config --global user.email "tu_email@ejemplo.com"`
2. **Clonación del repositorio:**
   `git clone https://github.com/jhonjayderavila26-web/tutorial-git.git`
3. **Añadir archivos:**
   `git add .`
4. **Confirmar cambios (Commit):**
   `git commit -m "docs: mensaje descriptivo"`
5. **Enviar cambios:**
   `git push origin main`
